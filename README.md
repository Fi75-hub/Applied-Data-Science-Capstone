# SpaceX Landing Prediction — Capstone Report

A 25-page presentation about predicting Falcon 9 first-stage landing outcomes. It discusses data collection, exploratory analysis, SQL queries, maps, a dashboard and classification models.

[Read the report](Data%20Science%20Capstone%20Project%20Report.pdf)

## Repository contents

This repository currently contains the report only. The notebooks, datasets and Dash script listed in the presentation have not been added here, so its results cannot yet be reproduced from this repository.

The report includes a file checklist for the full project. Those source files are needed to verify the analysis and run the dashboard.
